Quem opera

Dados acessados na conta do YouTube

Ao autorizar o app, o operador concede acesso à própria conta do YouTube para:

  • enviar vídeos ao canal (escopo youtube.upload);
  • publicar comentários em vídeos do canal (escopo youtube.force-ssl);
  • ler dados de métricas do canal, em modo somente leitura, pela YouTube Analytics API.

O token de acesso fica salvo apenas no servidor onde o app roda, em um arquivo de uso restrito. Ele não é compartilhado com terceiros.

Uso de dados pelo app

O app não coleta dados de visitantes de nenhuma página. Os dados usados na produção de cada vídeo (textos de roteiro, termos de busca, arquivos de mídia) são enviados apenas aos serviços necessários para gerar o conteúdo:

  • Google Gemini, para roteiro, imagem, vídeo e narração;
  • YouTube Data API, para upload, comentários e consulta de vídeos em alta;
  • Pexels, para buscar imagens e vídeos de banco de mídia;
  • archive.org, para buscar material de domínio público.

Não vendemos nem compartilhamos dados com outras empresas, e não usamos dados para publicidade.

Uso de dados obtidos por APIs do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Retenção e exclusão

Os vídeos gerados e os dados de produção ficam no servidor do operador até ele removê-los. Para revogar o acesso do app à conta do YouTube a qualquer momento, use myaccount.google.com/permissions.

Alterações

Esta política pode ser atualizada. A data no topo indica a última revisão.
